# Release 39 — PDF Readability & Mobile Multi-Select

## PDF improvements
- Increased PDF typography for headers, metadata, day title, theme/notes, table headers, and table rows.
- Centered all PDF text, including mixed Arabic/English content.
- Centered the premium header content while keeping the group logo anchored on the left.
- Enlarged the Theme and Day Notes cards in the PDF and preserved multi-line text.
- Increased HTML-to-canvas render scale for sharper PDF text.

## Day Theme & Notes editor
- Theme is now a multiline textarea when creating or editing a day.
- Day notes area is larger and resizable.
- Both fields support explicit line breaks that are preserved in the PDF.

## Mobile-friendly assignment
- Replaced native multi-select controls with touch-friendly multi-choice cards.
- Multiple chefs can be selected by tapping names; no Ctrl/Cmd key is required.
- Selected chefs appear as removable chips with a selected count.
- Added the same responsive interaction for helper teams.
- Added clear-all actions for people and teams.

## Database
- No SQL changes are required for this release.
